# Mudrac – The Engineer's Slack Bot

Built for Stardance. Dad jokes + component finder.

## Commands

| Command | Description |
|---|---|
| `/mudrac` | Just says hi |
| `/mudrac <question>` | Get advice (try: servo, motor, wifi) |
| `/coffee` | Coffee wisdom |
| `/motivate` | Engineering pep talk |
| `/fun` | Electronics dad joke |
| `/find <category>` | Find components (wifi, imu, sensor, etc.) |
